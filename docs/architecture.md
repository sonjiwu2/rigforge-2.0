# Как устроен RigForge

## Разделы

Три раздела переключаются по hash в адресе: `#build`, `#catalog`, `#saved`. Текущий раздел отдаёт хук `useHashView`, кнопки «назад» и «вперёд» в браузере работают. `App.tsx` держит разделы в разметке и скрывает неактивные атрибутом `hidden`, каталог появляется при первом открытии. Окно с подробностями о детали — `<dialog>` поверх текущего раздела.

## Состояние

Общее состояние хранится в трёх хуках, `App.tsx` связывает их и передаёт данные разделам через props:

- `useAppState` — текущая сборка, сохранённые сборки, отзывы, предупреждение о хранилище, тост и запрос подтверждения;
- `useMoney` — выбранная валюта, курсы и подпись курса в шапке, вызывается внутри `useAppState`;
- `useCatalog` — категория, поиск, фильтры, сортировка, статус загрузки, найденные товары и слот, для которого ищут замену.

Компоненты из `features/` только рисуют эти данные и вызывают переданные функции (`onAdd`, `onRemove`, `onSave` и т. д.). Своей копии сборки у них нет, в `useState` лежит только то, что нужно самому компоненту: черновик фильтров, строка поиска, открытое меню.

## Данные

Товар после загрузки приводится к одному виду (`core/products.ts`), общие типы лежат в `types/index.ts`:

```
{ id, category, manufacturer, name, model, priceMinor, currency, offers, specs, imageUrl, popularity, ... }
```

- Цены хранятся в пенсах целым числом (`priceMinor`), чтобы не было ошибок округления. Неизвестная цена — `null`, а не 0.
- Курсы валют применяются только при выводе и вводе сумм (`utils/format.ts`), в сборках суммы всегда в фунтах.
- В сборку попадает короткая копия товара (snapshot), поэтому сохранённые сборки открываются без запросов к API.

## Запросы и ошибки

`api/vantaspec.ts`:

- каждый запрос проверяет `response.ok` до чтения JSON; ответы 404, 429, 500, сетевая ошибка, таймаут 12 секунд и не-JSON дают `ApiError` с понятным сообщением;
- `useCatalog` при новом запросе отменяет ожидание прошлого через `AbortController` и сверяет номер запроса, поэтому поздний ответ не заменит свежий;
- загруженная категория кешируется в памяти, после ошибки кеш очищается и «Повторить» запрашивает её заново;
- если модель пропала из VantaSpec, остальные модели категории всё равно загружаются.

`api/currency.ts` при сбое основного адреса пробует запасной. Если курсов нет, цены показываются в фунтах. `api/wikipedia.ts` загружает описание серии, его ошибка не мешает остальному окну подробностей.

В каталоге четыре состояния: «Загрузка…», товары, «Ничего не найдено» и ошибка с кнопкой «Повторить».

## Хранение

`core/storage.ts` хранит сборки, отзывы и валюту под одним ключом `rigforge:state:v1` и проверяет данные при чтении и записи. `useAppState` сохраняет их сразу после каждого изменения. Если `localStorage` недоступен, сайт работает, но предупреждает, что после закрытия вкладки данные не сохранятся.
